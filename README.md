# knowledge

Find designs with evidence that they do what you need.

Publish what a design must do, the design itself, and a report showing how it was
tested. Search by capability—“moves water” can find pumps, buckets, or aqueducts—and
see what is verified and what still needs work.

Sellers can offer physical products or access to the designs and test evidence.
Every version has a permanent fingerprint and a history. Hosts can share the
catalog while controlling access to paid content.

Initial Rust prototype: local cache, signed artifacts, search, and an agent API.
